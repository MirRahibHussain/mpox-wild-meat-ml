Outputs regenerated by the scripts in `src/`, on the restricted analytic sample
(2,262 carcass handlers in 56 villages).

- `inference.json`         discrimination, village cluster bootstrap CIs, paired model
                           differences, calibration deciles, slope and intercept
- `robust_fair.json`       outcome-definition robustness and the subgroup audit with
                           bootstrap intervals for the Baka-minus-other gap
- `shapley_final.json`     per-respondent Shapley values, block means with bootstrap
                           intervals, per-column normalisation, and the alternative partition
- `shapley_individuals.json` per-respondent values from the primary grouping
- `index_final.json`       complexity/accuracy sweep, final scorecard, calibration bands
- `roc2.json`              ROC curve points for the three classifiers
